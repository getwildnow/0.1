# ============================================
# SETUP INSTRUCTIONS
# ============================================
#
# 1. SUPABASE:
#    - Go to https://supabase.com and create a project
#    - Run migrations from supabase/migrations/ folder
#    - Copy URL and keys from Settings > API
#
# 2. VERIFF:
#    - Go to https://station.veriff.com/ and create an account
#    - Get API key and secret from Settings > API Keys
#    - Set up webhook: Settings > Webhooks
#      - Endpoint: https://your-domain.com/api/webhooks/veriff
#      - Events: verification.status.changed
#      - Copy API secret for signature verification
#
# 3. OPENAI:
#    - Go to https://platform.openai.com
#    - Create API key in Settings > API keys
#    - Add billing/payment method
#
# 4. CREATE .env.local:
#    - Copy this file to .env.local
#    - Fill in all values above
#    - Restart dev server: npm run dev
