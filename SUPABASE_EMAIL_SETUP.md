# Supabase Email Template Setup

> **✅ STATUS: READY TO USE**
> 
> This email template is production-ready and configured to redirect employees to `/employee-verification`.
> The template uses Brevo SMTP for reliable delivery.
>
> **Quick Setup:** See `QUICK_EMAIL_SETUP.md` for a 2-minute copy-paste guide.

---

## Important: Environment Variables

### Production (Railway)
Make sure Railway has:
```bash
NEXT_PUBLIC_BASE_URL=https://www.getwild-now.com
```

### Local Development
Make sure your `.env.local` has:
```bash
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```

**After updating environment variables, redeploy on Railway!**

## Email Template Configuration

### Step 1: Access Supabase Dashboard

1. Go to your Supabase project: https://supabase.com/dashboard
2. Navigate to **Authentication** → **Email Templates**
3. Select **Invite user** template

### Step 2: Configure the Invite Email Template

**What this template does:**
- Uses your brand colors and logo
- Shows the company name dynamically using `{{ .Data.company_name }}`
- Includes a "Start Verification" button that redirects to `/employee-verification`
- Mobile-responsive and works across all email clients
- Professional footer with contact information

**How the redirect works:**
- The `{{ .ConfirmationURL }}` variable is automatically generated by Supabase
- It includes the invite token and redirects to: `https://www.getwild-now.com/employee-verification`
- This is configured in your API route (`app/api/employees/invite/route.ts` line 96)

## Troubleshooting Email Delivery Issues

### Issue: Emails not being sent

**Possible causes:**

1. **Rate Limiting (Development)**
   - Supabase free tier limits: 3 emails per hour
   - **Solution**: Upgrade to Pro plan or configure custom SMTP

2. **SMTP Not Configured**
   - Default Supabase SMTP has strict limits
   - **Solution**: Configure custom SMTP (Gmail, SendGrid, AWS SES)

3. **Emails Going to Spam**
   - **Solution**: Check spam folder, configure SPF/DKIM records

4. **Wrong Base URL**
   - **Solution**: Ensure `NEXT_PUBLIC_BASE_URL=https://www.getwild-now.com` in Railway environment variables

### Configure Custom SMTP (Recommended for Production)

1. Go to Supabase Dashboard → **Project Settings** → **Auth**
2. Scroll to **SMTP Settings**
3. Enable **Enable Custom SMTP**
4. Configure with your SMTP provider:

**Example with Gmail:**
```
Host: smtp.gmail.com
Port: 587
Username: your-email@gmail.com
Password: [App Password - not your regular password]
Sender email: your-email@gmail.com
Sender name: Get Wild
```

**Example with SendGrid:**
```
Host: smtp.sendgrid.net
Port: 587
Username: apikey
Password: [Your SendGrid API Key]
Sender email: noreply@getwild-now.com
Sender name: Get Wild
```

### Check Email Logs

1. Go to Supabase Dashboard → **Authentication** → **Logs**
2. Look for email events
3. Check for errors or delivery status
